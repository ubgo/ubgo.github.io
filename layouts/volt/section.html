Volt, now part of ubgo

Build, release and ship Go CLIs, in any repo layout.

Volt is the layer on top of ubgo. The volt tool scaffolds a CLI, runs the CI gate, builds for every platform and makes tagged releases it checks after publishing. The kit modules give your CLI the parts every CLI needs, one go get at a time.

One tag rule for every layout

Libraries tag by directory path, because that is the only shape the Go module proxy resolves. CLIs tag by binary name. A repo that holds one thing tags bare. The same rule works for a single CLI, a library, a monorepo of CLIs and mixed repos.

{{ transform.Highlight "v1.4.0 the repo root\nnotes/v1.4.0 a CLI at cmd/notes (tag = binary name)\npkg/textutil/v0.1.0 a library submodule (tag = directory path)" "text" "" }}

From the voltkit README, "The tag grammar".

See it on a real monorepo

volt-demo-clis holds two CLIs, a root library and nested libraries. volt status shows every releasable stream and only those:

$ volt status
.                library  v0.1.0    up to date

cmd/snap         cli      v0.1.0    up to date
pkg/mathx        library  v0.1.0    up to date
pkg/textutil     library  v0.1.0    up to date

From the volt-demo-clis README. pkg/testutil is marked internal: true, so it is tested but never listed or released.

Start a CLI

volt-cli holds the templates. They are fetched at a pinned tag, never main, so a bad commit there cannot break scaffolding.

$ volt new cli mytool                      # minimal
$ volt new cli mytool --template cobra
$ volt new cli --list
VariantGives you
minimalstdlib-only CLI: flag parsing, version stamping, zero dependencies
cobracobra root command with --version

From the volt-cli README.

Run it in CI

volt-action installs the released Volt binary, checksum-verified, and runs one command. It has no logic of its own; the pipeline lives in the binary.

{{ transform.Highlight "- uses: ubgo/volt-action@v1\n with: { args: ci }" "yaml" "" }}

From the volt-action README. A release hook can stop a release before anything is created, as the volt-demo-clis README shows:

$ RELEASE_BLOCKED=1 volt release ./cmd/notes --bump patch
hook pre_release: ./scripts/release-gate.sh
gate: releases are blocked (RELEASE_BLOCKED=1) — refusing notes/v0.2.1
Error: pre_release hook refused the release — nothing was tagged
