Batteries included for Go, one module at a time.

ubgo is an ecosystem for building Go apps, in the spirit of the components Laravel ships for caching, logging and configuration. Every piece is its own Go module, so a service imports only what it uses. The main libraries share one shape, a small core with adapters outside it and a shared test suite, so learning one teaches you the next.

New: Volt

From libraries to a shipped program

ubgo libraries are the parts your code runs on. Volt is the layer on top: the volt tool scaffolds a CLI, runs the CI gate, builds for every platform and makes releases it checks after publishing, and its kit modules give a CLI the parts every CLI needs.
