About ubgo

ubgo is a collection of open-source libraries, mostly for Go, with a few for TypeScript. Each library does one job and lives in its own repository, so a service imports only the parts it uses. There are {{ len $d.libraries }} public libraries across {{ len $d.areas }} areas.

ubgo is maintained by Aman Bansal. Issues and pull requests go to each library's own repository.

Go libraries install with go get github.com/ubgo/<name>. A few repos use a different module path or a sub-module; each library page shows the exact line from its README.
