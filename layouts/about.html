About

Why ubgo exists

Building an app means solving the same problems again and again: errors, logs, caching, configuration, locks, health checks, shutting down cleanly. Laravel answers that for PHP with components for caching, logging, configuration and more that come with the framework. ubgo is that kind of ecosystem for Go, batteries included to build apps.

The difference is how it is packaged. Every piece is its own open-source Go module, so a service imports only what it uses. The main libraries share the same conventions, a small core, adapters outside it and a shared test suite, so learning one teaches you the next.

How ubgo compares

ubgo is not one framework you adopt whole. It is a set of Go modules that follow the same rules. Every point below is checked against the repos.
