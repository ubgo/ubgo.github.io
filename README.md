# ubgo.github.io

The website for [ubgo](https://github.com/ubgo), served by GitHub Pages at https://ubgo.github.io. Built with Hugo and the standalone Tailwind CLI, so no Node is needed to build or run it.

## Layout

| Path | What it is |
| --- | --- |
| `data/libraries.yaml` | The one list of public libraries, areas and principles, plus curated links (family, examples repo, interop, replaced by, conformance suite). The site and the org profile README are generated from it. |
| `data/facts/<name>.json` | Facts read from each public repo (Go version, direct deps, license, latest tag, Go modules, contrib/ adapters, packages, ubgo dependencies, README code, highlights and tables). Generated by `task facts`; never edit by hand. |
| `data/picker.yaml` | The "which package do I need?" decision tree; every result names the README it is based on. |
| `data/brand.json` | Copy of `brand/brand.json`, written by `task brand`. |
| `content/libraries/_content.gotmpl` | Makes one page per library from the data file. |
| `layouts/` | Templates: home (with the live hero diagram), library index, library page (architecture diagram, code tabs), map, explainers, picker, brand, about, 404, robots.txt, and `home.json` (the search index for the Ctrl/Cmd+K palette). |
| `content/explainers/` | One page per explainer; the step captions live in front matter. |
| `layouts/_partials/profile-readme.md` | Template for the org profile README (`ubgo/.github`, `profile/README.md`). |
| `assets/css/main.css` | Tailwind input. `task css` builds `assets/css/site.css`. |
| `assets/js/` | `site.js` is the one bundle (Hugo `js.Build`); it imports `base.js` (theme, copy, index filter, phone menu), `hero.js`, `map.js`, `explainers/`, `codetabs.js`, `picker.js`, `palette.js` and `brand.js`. Each module only runs when its markup is on the page. |
| `static/` | Logo, favicons and social card (`task brand`), `static/brand/` with every brand file and the download zip (`task brand`), `static/og/<name>.png` per-library social cards (`task og`), and `static/fonts/` with the self-hosted OFL fonts. |
| `content-preview/` | The `/preview/` page (logo options, rendered profile README). Only built with `--environment preview`. |
| `config/` | `_default` (production), `preview` (owner preview), `profile` (README generation). |
| `scripts/linkcheck.py` | Checks every internal link and asset in a build. |
| `scripts/install-tools.sh` | Installs the pinned Hugo and Tailwind binaries with checksum checks. |
| `scripts/facts.py` | Reads the facts above from shallow clones of the repos (`task facts`). |
| `scripts/og/` | Builds the per-library social cards with resvg (`task og`, needs Node; the site itself does not). |
| `scripts/brand-zip.py` | Builds `static/brand/ubgo-brand.zip`. |

## Tasks

```sh
task tools       # install pinned Hugo extended 0.167.0 and Tailwind 4.3.3 into ~/.local/bin
task brand       # copy every brand file and brand.json from ../brand, rebuild the zip
task facts       # refresh data/facts/ from the public repos (needs network)
task og          # rebuild static/og/<library>.png social cards (needs Node)
task build       # production build into public/
task serve       # preview at https://ubgo.shipd.fyi through portless (owner login only)
task profile     # regenerate ../profile/profile/README.md from data/libraries.yaml
task linkcheck   # build, then check every internal link
task check       # profile + build + link check
```

## Adding a library

Add an entry to `data/libraries.yaml` (only public repos), then run `task facts og check`. That updates the site and the org profile README together, so they never drift.
